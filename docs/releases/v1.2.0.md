# SimulGroove Music v1.2.0

本次小版本聚焦在线音乐可用性、跨设备同步可靠性与本地音乐库性能，并保持 v1.1.0 的安装与更新方式不变。

## 新增

- **在线搜索免登录**：搜索接口允许匿名访问，并按来源 IP 限流；播放、下载、歌词与封面仍要求登录。搜索框清空后保留上次结果，空关键字不再发起请求。
- **在线搜索分页**：接入 sidecar 游标分页，歌手与专辑集合页可继续加载后续结果。游标有有效期，失效游标返回空页；每个上游来源只提供一页结果，因此可加载的结果总数受来源限制。
- **客户端固定正式后端**：登录页与个人页不再展示或提供服务器地址输入，客户端默认连接 `https://music.zonwe.top`，本地联调仍可用 `--dart-define=MUSIC_API_URL=...` 在编译期覆盖。
- **自动检查与自动下载拆分**：自动检查更新默认开启，最多每 24 小时执行一次，失败也按间隔重试；自动下载默认关闭，需在设置中显式开启。开启后启动检查会在后台下载并校验 SHA-256，安装前仍请求用户确认，重复下载会被串行化。

## 改进

- **封面拆表（schema v6）**：封面从 `Tracks` 移到独立的 `track_artworks` 表，v5→v6 迁移保留歌单与喜欢引用。列表查询不再读取整库封面，界面按可见行取图，播放器按当前曲目懒加载封面并按显示尺寸解码。
- **查询与订阅收敛**：一次设置写入从 12 条 `AppSettings` 查询降到 1 条；歌单详情改用 `playlistTracksProvider`，同步不再逐歌单建立流订阅；专辑与艺术家网格索引由 O(n²) 改为 O(1)。
- **大库扫描与同步**：扫描来源重建改为分块删除，同步占位清理改用 `NOT EXISTS`，避免大库触碰 SQLite 变量上限。
- **返回行为**：从正在播放页返回时回到进入前的音乐库、在线搜索或设置页，不再强制跳转歌单。

## 修复

- **跨设备歌单同步**：同名同艺术家的重复曲目不再触发同步主键冲突，并清理在线占位；曲目匹配并列时按时长决胜，时长相差超过 3 秒不匹配；删除墓碑会撤回全部同内容副本。
- **后端转发头**：改用 .NET 10 的 `KnownIPNetworks`，消除 `ASPDEPR005` 编译告警，容器入口代理的信任开关按预期生效；补充“默认只信任回环、不采信 `X-Forwarded-Host`”的回归测试。
- **Android 权限**：清单移除未使用的 `RECORD_AUDIO`，与听歌识曲仍是占位页的事实保持一致。

## 升级说明

- Windows：安装版可在应用内升级；便携版不自动下载安装器，仍按手动方式更新。
- Android：与 v1.1.0 使用同一发布密钥，可直接覆盖安装（`versionCode` 递增，无需卸载）；仍需允许“安装未知应用”，并在系统安装界面确认。
- 数据库：v5→v6 自动迁移，歌单、喜欢与封面数据保留。该迁移不可逆，降级到 v1.1.0 前需要从备份恢复数据库。

## 已知限制

- 在线播放与下载仍需登录；Web 因认证请求头限制仍不开放在线播放和下载。
- 在线搜索结果总数受上游来源分页能力限制，单个来源只返回一页。
- 听歌识曲仍是占位功能。
- Linux 与 Web 不支持应用内更新。
- Windows 安装器与 exe 未做 Authenticode 签名，SmartScreen 会提示“未知发布者”。
