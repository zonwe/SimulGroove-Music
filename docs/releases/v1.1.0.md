# SimulGroove Music v1.1.0

本次版本为 Windows 和 Android 增加安装包分发与应用内更新。

## 新增

- **Windows 安装器**：基于 Inno Setup 6，按当前用户安装到 `%LOCALAPPDATA%\Programs\SimulGroove Music`，无需管理员权限；同一安装会原地升级，卸载与升级不会删除 `Documents` 中的数据库或 `%APPDATA%` 中的应用数据。
- **Windows 应用内更新**：设置页手动检查，启动时默认每 12 小时检查一次（可关闭）。下载后校验 SHA-256，退出应用后由更新助手静默运行安装器并重新启动；失败会写入标记，下次启动提示。
- **Android 应用内更新**：按当前 ABI 选择 APK，下载并校验 SHA-256 后通过 FileProvider 交给系统安装界面。需要允许“安装未知应用”，系统会校验签名并拒绝降级。
- **更新源**：统一读取 GitHub Release 中的 `latest.json`；自建分发可用 `--dart-define=UPDATE_MANIFEST_URL=...` 覆盖。
- **发布自动化**：`.github/workflows/release.yml` 在 tag 或手动触发时构建 Windows 安装器/便携包、三个 ABI 的 APK、`latest.json` 与 `SHA256SUMS.txt`。

## 安装说明

- Windows：优先使用 `SimulGroove-Music-v1.1.0-windows-x64-setup.exe`；解压版 zip 仍可使用，但解压版只能手动更新。
- Android：安装与设备 ABI 匹配的 APK。v1.0.0 没有更新功能，且使用开发机 debug 证书；如果本版改用新的发布密钥，Android 会拒绝覆盖安装，需要先卸载旧版（会清除应用数据）再安装本版。若希望保留 v1.0.0 的音乐库与设置，可用原来的 `%USERPROFILE%\.android\debug.keystore`（密码通常为 `android`，别名 `androiddebugkey`）作为发布密钥，或先通过账号同步备份歌单/喜欢/均衡器。之后只要签名密钥不变即可在应用内更新。
- Android 正式发布必须配置固定签名密钥（`ANDROID_KEYSTORE_BASE64`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`、`ANDROID_STORE_PASSWORD`）。没有配置时发布工作流会失败，避免产出无法自更新的 APK。

## 已知限制

- Linux 与 Web 不支持应用内更新；Linux 仍按发行包手工升级。
- Windows 安装器与 exe 未做 Authenticode 签名，SmartScreen 会提示“未知发布者”。
- Android 不能静默安装，用户必须在系统安装界面确认；相邻版本必须使用同一签名，且 `pubspec.yaml` 的 `+build` 必须递增。
- 更新源使用公开 GitHub Release；仓库私有或改名后需要同步修改默认清单地址。
